# Outfit Manager / 穿搭管理器

给 SillyTavern 用的穿搭管理插件。它可以管理 User 和角色的衣柜，也可以从穿搭世界书里按场景生成一套当前服饰，再把最终穿搭注入到发给 AI 的提示词里。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 衣柜管理 | 上传图片、填写描述、按分类/风格/季节/场景管理穿搭 |
| User/角色独立衣柜 | User 和每个角色都有独立穿搭与当前穿着状态 |
| 场景按钮 | 外出、约会、通勤、家居、运动、睡前，一键让 AI 给 User 生成穿搭 |
| 随机搭配 | 从已有衣柜或穿搭世界书中 roll 一套，并弹窗确认 |
| 世界书兼容 | 支持 uu 现代、uu 内衣、SFW 这类穿搭世界书 |
| 提示词注入 | 普通聊天时只发送当前穿搭，不把整本穿搭世界书发给 AI |
| 批量添加 | 支持批量上传图片，并粘贴外部 AI 返回的穿搭描述 |
| AI 识图 | 可用 OpenAI 兼容视觉 API 批量生成穿搭描述/标签 |

## 安装

在 SillyTavern 中打开：

```text
扩展管理 -> 安装插件 -> 输入仓库地址
```

仓库地址：

```text
https://github.com/gabby1111111111/Outfit-Manager
```

安装后重启 SillyTavern，并在扩展管理里启用插件。

## 推荐世界书

当前 OM 的世界书列表只识别名字里包含以下关键词的世界书：

```text
uu
SFW
```

推荐导入：

```text
uu现代
uu内衣
SFW
```

这三本世界书不需要挂全局。只要已经导入 SillyTavern，OM 就可以在随机页和场景按钮中单独读取它们。

如果你把这三本挂到了全局世界书，OM 也会在普通聊天请求发送前剔除穿搭条目，避免整本穿搭世界书被发给 AI 浪费 token 或干扰剧情。

## 场景按钮

打开 OM 面板后，顶部会显示：

```text
外出 / 约会 / 通勤 / 家居 / 运动 / 睡前
```

点击这些按钮时，流程是：

```text
读取 uu/SFW 穿搭世界书
-> 按当前场景过滤相关风格
-> 读取 User 人设、当前输入、最近聊天、当前 char 信息
-> 调用 SillyTavern 当前主 API 生成 User 的穿搭
-> 弹窗展示，可编辑，可确认，可保存到衣橱
```

注意：场景按钮固定给 `User` 生成穿搭，不给 `char` 生成。`char` 的人设只作为当前剧情、关系、场合参考。

## User 人设

场景按钮生成时会尝试读取 User 信息：

```text
User 名称
User persona_description / 用户人设
```

如果 SillyTavern 当前版本没有暴露相关字段，OM 会降级为只使用当前输入和聊天上下文。

## 随机搭配

底部骰子按钮会打开随机搭配页。

随机搭配支持：

```text
衣柜 + 世界书混合 roll
仅 roll 世界书
按风格过滤
按季节过滤
按场景过滤
套装优先 / 仅套装 / 单品组合
```

点击“随机搭配！”后会弹出结果窗口。你可以直接应用，也可以继续调整。

## 衣柜随机

底部“衣柜随机”按钮只从当前衣柜里已有的套装随机选一套：

```text
不读世界书
不调用 AI
有图片时会弹出图片预览
```

## 世界书格式兼容

OM 支持两类穿搭世界书格式。

第一类是 uu 风格的部件格式：

```text
<纯欲风穿搭刻画>
- 核心风格：...
- 生成规则：...
- 上衣：...
- 下装：...
- 配饰：...
- 鞋袜：...
</纯欲风穿搭刻画>
```

第二类是 SFW 风格的搭配指导格式：

```text
<新中式禅意松弛风>
定义: ...
单品: ...
配色: ...
妆容搭配: ...
可选配饰: ...
可选鞋履: ...
搭配技巧: ...
搭配示例:
  - 上衣+下装+鞋袜+配饰
</新中式禅意松弛风>
```

OM 会保留完整世界书条目给 AI 参考，但普通随机时也能从“搭配示例”里抽出一套可用结果。

## 普通聊天注入

OM 的生成和注入是两件事：

```text
场景按钮 / 随机搭配 = 生成或选择当前穿搭
普通聊天发送 = 把当前穿搭注入给 AI
```

普通聊天时，OM 会：

```text
读取 User 当前穿搭
读取角色当前穿搭
剔除 uu/SFW 穿搭世界书条目
按设置注入到 user/context/system 位置
```

推荐设置：

```text
注入位置：用户消息末尾
注入方式：仅文字描述
```

## 场景规则

默认场景大致如下：

| 场景 | 说明 |
| --- | --- |
| 外出 | 日常外出、逛街、普通社交 |
| 约会 | 更精致、更有氛围感的穿搭 |
| 通勤 | 办公、上班、职场感 |
| 家居 | 居家、舒适、松弛 |
| 运动 | 运动、机能、街头运动 |
| 睡前 | 睡衣、睡前氛围 |

家居和睡前不会主动搭配内衣世界书。
